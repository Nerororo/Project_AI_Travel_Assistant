# Template Source Instructions

## Responsibility

- 이 폴더는 Travela 원본 템플릿 보관용이다.

## Boundaries

- Routy 서비스 기능을 이 폴더에 구현하지 않는다.
- 원본 템플릿의 파일, 라이브러리, 이미지, 라이선스 표기는 명시적 요청 없이 수정하거나 삭제하지 않는다.
- Routy 화면 변경은 `Routy`에서 수행한다.
- 최신 제품 계약은 `docs/01-requirements.md`와 `src/main/resources/static/Routy/INTEGRATION.md`를 따르며 원본 템플릿 내용을 현재 Routy 동작의 근거로 사용하지 않는다.
- 라이선스 확인이나 원본 비교는 읽기 전용으로 수행하고 산출물 반영은 별도 승인된 Routy 작업에서 한다.
