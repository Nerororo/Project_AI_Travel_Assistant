# Region Domain Instructions

## Responsibility

서울특별시·광역시·세종특별자치시와 도·특별자치도 아래 시·군을 최종 선택 항목으로 제공하고, 특별시·광역시 아래 구·군은 장소 검색 필터로 제공하는 국내 기준 데이터의 적재·검증·검색과 AI 허용 목록 제공을 관리한다.

## Rules

- 기준 데이터는 `src/main/resources/data/regions.json`을 단일 원천으로 사용한다.
- 출처가 확인된 공공 행정구역 자료와 대표 좌표만 사용한다.
- 기준 데이터에는 출처와 기준일을 기록하고 갱신 때 삭제·명칭 변경·상위 관계 변화를 검증한다.
- 최종 여행 지역은 하나만 허용한다. 서울특별시·광역시·세종특별자치시는 자체 선택하고 도·특별자치도는 최종 일정 입력에서 거부해 그 아래 시·군을 선택하게 한다.
- 특별시·광역시 아래 구·군은 장소 검색 필터로만 제공하고 AI 허용 목록과 완료 일정 regionId에서는 제외한다.
- 읍·면·동과 해외 지역을 포함하지 않는다.
- 애플리케이션 시작 시 ID 중복, 필수값, 상위 관계와 좌표 범위를 검증하고 잘못된 데이터로 시작하지 않는다.
- 검색과 정렬은 결정적이어야 한다.
- 검색은 공식 이름·짧은 이름·별칭을 사용하고 중복 이름에는 상위 지역을 함께 제공한다.
- AI는 region이 제공한 허용 ID만 선택할 수 있다.
- 카카오 검색 결과를 지역 기준 데이터에 복제하지 않는다.
- 장소 검색, AI 호출, 일정 저장과 경로 계산을 구현하지 않는다.
- 완료 일정에는 region Entity 참조 대신 regionId와 당시 표시 이름 snapshot을 전달한다.
