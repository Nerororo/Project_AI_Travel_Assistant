# Place Domain Instructions

## Responsibility

카카오 장소 검색, 지도 기반 숙소·음식점 탐색, 역할별 검색 정책, 카테고리 기반 기본 체류 시간과 `selectionToken`을 관리한다.

## Rules

- provider 통신은 `KakaoPlaceClient` 인터페이스 뒤 `place/client`에 둔다.
- K0-02A는 2026-09-11 완료됐다. 실제 Client, 좌표 기반 공개 endpoint와 token 전달 흐름은 좌표의 요청 범위 일시 사용·즉시 폐기 조건을 지켜 구현한다.
- 카카오 카테고리는 체류 시간으로 즉시 변환하고 API·DB에 유형을 노출하지 않는다.
- 관광지는 대표 좌표 20km 또는 주소 행정구역 일치 조건으로 선택 지역 소속을 검증한다.
- 숙소는 기하 중앙값 5·10km, 메도이드와 현재 지도 영역에서 검색하고 거리 점수로 자동 순위를 만들지 않는다.
- 음식점은 확정된 메뉴 검색어와 기준 관광지 또는 현재 지도 영역으로 검색하고 목록·지도 동기화에 필요한 일시 후보 정보를 반환한다. 음식점 품질 순위를 만들지 않는다.
- 카카오 장소명을 사용자 표시 이름의 기본값·placeholder로 복사하지 않는다.
- 좌표·주소·전화번호·카테고리·제공자 장소명·원문 응답과 검색 cache를 영속 저장하지 않는다.
- 완료 저장용 계약에는 카카오 장소 ID·URL, 역할과 사용자 작성 정보만 전달한다.
- `selectionToken`은 인증 사용자 ID를 서명 대상에 포함하는 짧은 수명의 토큰이며 서버 장소 저장소를 만들지 않는다.
- 좌표는 estimate·create 요청 지역 변수에서만 사용하며 요청 종료 뒤 참조 가능한 객체나 비동기 작업에 남기지 않는다.
- 일정 계산·경로 최적화·추천 점수를 구현하거나 AI를 직접 호출하지 않는다.
- Controller는 Entity를 반환하지 않는다.
