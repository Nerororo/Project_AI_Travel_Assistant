# Recommendation Domain Instructions

## Responsibility

음식점 후보의 설명 가능한 점수와 결정적 순위를 계산한다. 숙소는 이 도메인의 점수 추천 대상이 아니다.

## Rules

- 음식점은 식사 전후 위치의 이탈 비용을 사용한다.
- 음식점 품질·평점·리뷰를 추정하지 않고 Haversine 이탈이 같은 경우의 동률 규칙을 결정적으로 유지한다.
- 식사 시간 적합성을 먼저 검증하고 Haversine 이탈이 작은 순으로 정렬한다. 지도·목록 표시용 결과에는 직전·직후 기준과 임시 후보 좌표를 제공한다.
- 후보 없음과 provider 장애를 구분한다.
- 추천 결과를 사용자 선택이나 완료 일정에 자동 반영하지 않는다.
- 사용자가 확정한 음식점만 travelplan에 전달하며 미선택 식사는 장소 없는 상태를 유지한다.
- AI가 최종 점수·순위를 결정하게 하지 않는다.
- 장소 조회와 경로 계산은 place·route의 공개 Service·DTO를 사용한다.
- 외부 Client를 직접 생성·참조하거나 Repository에 접근하지 않는다.
- 완료 일정 조회 뒤 좌표가 없으므로 저장 일정 기반 재검색 기능을 임의로 만들지 않는다.
