# AI Package Instructions

## Responsibility

허용된 국내 지역 후보와 지역·관광지 맥락의 음식 메뉴 후보를 구조화하고 OpenAI 통신을 관리한다.

## Rules

- 지역 추천은 서버가 전달한 허용 목록에서 중복 없는 정확히 3개 ID와 이유를 반환한다.
- 메뉴 분석은 중복 없는 메뉴 1~5개, 카카오 장소 검색어, 짧은 이유와 선택적인 대상 관광지를 만든다. 결과는 사용자가 수정·삭제·확정할 수 있다.
- AI는 특정 식당을 선택·평가하거나 음식점 동선 순위를 결정하지 않는다.
- AI는 장소 ID, 거리, 시간표, 방문 순서, 추천 점수와 저장 성공을 결정하지 않는다.
- 통신은 `AiClient` 인터페이스 뒤로 분리하고 자동 테스트는 Fake를 사용한다.
- 구조화 응답과 DTO validation을 사용하며 목록 밖 ID와 계약 위반을 거절한다.
- 사용자 한도와 재시도는 API·운영 계약을 따른다.
- 메뉴 분석은 사용자당 3회/분·15회/일이고 잘못된 구조화 응답은 최대 한 번 재시도한다. 동일 `requestId` 재전송은 새 호출로 세지 않는다.
- 메뉴 분석이 재시도 뒤에도 실패하면 기존 작성 상태를 보존하고 사용자가 검색어를 직접 입력하게 한다.
- API 키, 사용자 원문과 provider 원문을 코드·Git·DB·로그·오류 응답에 남기지 않는다.
