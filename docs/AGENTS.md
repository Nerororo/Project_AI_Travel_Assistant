# Documentation Instructions

## Responsibility

`docs/`는 요구사항, 아키텍처, DB, API, 개발 방향, ADR, 준비도, 테스트, 운영, 완료 기준, 작업 순서와 하네스 경계를 관리한다.

## Rules

- 문서별 단일 책임은 `00-docs-index.md`를 따른다.
- 현재 작업과 직접 관련된 문서만 수정하고 목표 계약과 실제 구현 상태를 구분한다.
- 계약 수치를 여러 문서에 새로 복제하지 않고 책임 문서를 갱신한 뒤 다른 문서는 참조한다.
- API는 `04`, DB는 `03`, 결정 이유는 `06`, 현재 상태는 `07`, 완료 판정은 `10`, 작업 ID는 `11`, 쓰기 경계는 `12`가 기준이다.
- 문서 구조·번호를 임의로 바꾸지 않는다.
- 새 기준 문서를 추가하면 `00-docs-index.md`에 역할을 등록한다.
- 구현되지 않은 내용을 완료로 표시하지 않는다.
- 카카오 임시 사용 조건 확인만으로 좌표 기반 기능과 운영 배포를 완료 처리하지 않는다. 일시 사용·즉시 폐기 계약의 구현과 검증이 필요하다.
- 문서 전용 작업은 코드·테스트·설정·migration·정적 자산을 수정하지 않는다.
- `AGENTS.md`와 `12-harness-boundaries.md`는 별도 하네스 작업에서만 바꾼다.
- D0 문서 정렬은 완료됐지만 기능 구현은 시작 전이다. 문서 감사에서 구현 체크박스를 임의로 완료 처리하지 않는다.
