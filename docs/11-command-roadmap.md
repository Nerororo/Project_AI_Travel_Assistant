# Codex 대화형 구현 로드맵

## 사용법

한 번에 작업 ID 하나만 진행한다. 먼저 `설명만` 요청하고, 이해한 뒤 구현을 승인한다. 구현 후 테스트 결과와 완료 조건을 확인한 다음 다음 ID로 이동한다.

```text
P1-01을 설명만 해줘.
수정할 파일, 각 파일의 역할, 사용할 Spring 개념을 초보자 기준으로 설명해줘.
```

문제가 생기면 다음처럼 요청한다.

```text
P1-03에서 막혔어. 코드는 바꾸지 말고 원인과 선택지를 설명해줘.
```

## 전체 순서

```text
F0 개발 기반 → P1 Place CRUD → R1 거리·경로
→ T1 TravelPlan 기본 저장 → A1 AI 선호 분석
→ R2 추천 → T2 최종 일정 조합 → Q1 품질·운영 → U1 인증
```
